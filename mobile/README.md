# Kanban Mobile

Нативное Android-приложение команды на Kotlin и Jetpack Compose. Sprint 1 добавляет отдельную вкладку расписания, события и настройки.

## Быстрый запуск

1. Откройте каталог `mobile` в Android Studio.
2. Выберите JDK 17 (встроенный JBR Android Studio подходит).
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на эмуляторе с Android 8.0 (API 26) или новее.
5. Войдите под тимлидом `alexey / lead123` или участником `maria / member123`.

Проверка из терминала Windows:

```powershell
cd mobile
.\gradlew.bat test assembleDebug
```

APK после сборки: `mobile/app/build/outputs/apk/debug/app-debug.apk`.

## Реализовано в Sprint 0

- вход по логину и паролю с разделением прав;
- Kanban-доска с четырьмя статусами;
- создание задачи для тимлида, карточка задачи, смена статуса, файлы и комментарии;
- история выполненных задач с поиском и фильтрацией;
- список участников и публичный профиль участника;
- управление командой, блокировка пользователей и создание аккаунтов для тимлида;
- выбор временного пароля при создании аккаунта;
- права на смену статуса: исполнитель работает со своей задачей, тимлид принимает результат;
- выбор дедлайна задачи через системный календарь;
- фильтрация истории за 7/30 дней или за всё время;
- список команд, карточка команды, выбор рабочей команды, вступление и выход;
- личный профиль со статистикой;
- дополнительные разделы расписания групп 203/204 и событий;
- единая с веб-клиентом цветовая система и геометрия компонентов.

## Sprint 1

- пять вкладок: доска, расписание, история, участники, профиль;
- общая лента пар, командных/групповых/личных событий и дедлайнов задач;
- цветовое разделение лекций, практик и лабораторных;
- создание событий, собственных типов с цветом и локальных напоминаний;
- светлая/тёмная тема и выбранная группа сохраняются между запусками;
- горизонтальные переходы между экранами, системный жест назад, единые Material-иконки.
- аватар в верхней панели открывает профиль; заголовок списка задач участника следует выбранной теме.
- на всех вложенных экранах используется единая кнопка «Назад» с Material-стрелкой и областью нажатия не менее 48 dp.
- пользовательский тип события создаётся в отдельном диалоге, а не в общей форме события;
- корневой экран учитывает радиусы углов устройства при системном жесте возврата.
- на доске можно переключать проекты выбранной команды; задачи разделены по проектам;
- у события выбираются начало, окончание и описание; из ленты открывается экран его деталей;
- нажатие на участника открывает его профиль, а «Назад» возвращает на прежний экран.
- анимируемый экран клипируется по радиусам устройства, чтобы при возврате между экранами не появлялись прямоугольные края.

Пары, задачи и пользователи пока демонстрационные. Созданные события, типы и настройки сохраняются только на устройстве. Точки интеграции с backend и ограничения описаны в корневом [MOBILE_DEVELOPMENT.md](../MOBILE_DEVELOPMENT.md).
