# Код в сапоге — Android

Мобильный клиент студенческого таск-трекера «Канбан-доска»: доски проектов, расписание ИСУ и команды, история, профиль.
Kotlin + Jetpack Compose + Material 3. Версия `0.5.3-demo` — Спринт 3, классический дизайн.

Документация:
- [docs/PROJECT.md](docs/PROJECT.md) — о проекте: роли, функции, права, что сделано по спринтам, ограничения;
- [docs/CODE.md](docs/CODE.md) — карта кода: что где лежит, как устроены слои, как подключить API и ИСУ;
- [docs/AUDIT.md](docs/AUDIT.md) — сверка ТЗ с кодом: что работает, что сделано в доработке, что зависит от backend.
- [docs/BACKEND_INTEGRATION.md](docs/BACKEND_INTEGRATION.md) — состояние подключения к Swagger, готовые запросы и оставшиеся шаги.

Функции, которых нет в вебе (удаление аккаунта, роли капитана, удаление проекта, файлов задач и типов событий),
по ТЗ не удалены, а заблокированы до решения команды. Включаются переключателями в `core/features/Features.kt`.

## Запуск

1. Откройте папку `mobile` в Android Studio (JDK 17, Android SDK 37).
2. Gradle Sync → конфигурация `app`. Версию выберите в Build Variants (см. ниже). Поддерживаются Android 10–17 (minSdk 29, targetSdk 37).
3. Из терминала: `./gradlew test assembleCleanDebug assembleMockDebug` (Windows: `gradlew.bat`).

Приложение работает в **демо-режиме**: локальный «сервер» проверяет права как backend и сохраняет данные
на устройстве между запусками. Расписание пар берётся с ИСУ УУНиТ и кэшируется на устройстве.

## Две версии: clean и mock

| | `clean` (по умолчанию) | `mock` |
|---|---|---|
| Название на телефоне | «Код в сапоге» | «Код в сапоге (мок)» |
| applicationId | `com.kanbanboard.mobile` | `com.kanbanboard.mobile.mock` — ставится рядом с clean, данные раздельные |
| Данные при первом запуске | только тимлид и участник, остальное создаёте вы | 9 аккаунтов, 3 проекта, задачи во всех колонках, история, события, файлы, уведомления |
| Без ИСУ и кэша | пар нет, предупреждение | пример расписания с предупреждением |
| Сборка | `./gradlew assembleCleanDebug` | `./gradlew assembleMockDebug` |

Аккаунты clean:

| Роль | Логин | Пароль |
|---|---|---|
| Капитан (тимлид) | `nikita` | `lead12345` |
| Участник | `samir` | `member12345` |

Аккаунты mock:

| Роль | Логин | Пароль |
|---|---|---|
| Капитан | `nikita`, `alexey` | `lead12345` |
| Участник, группа 203 | `samir`, `denis`, `ilya` | `member12345` |
| Участник, группа 204 | `radmir`, `almaz`, `alena`, `maria` | `member12345` |

В mock у участников разные настройки приватности расписания, чтобы были видны все варианты:
`nikita` — название, `radmir` — название и описание, `alena` — ничего, остальные — «Занят».

Сбросить данные любой версии — «Очистить хранилище» приложения в настройках Android.

## Настройка ИСУ

Адрес и названия групп задаются свойствами Gradle (в `gradle.properties` или через `-P`):

```
isuUrlTemplate=https://isu.uust.ru/class_schedule/?group={group}
isuGroup203=203
isuGroup204=204
```

`{group}` подставляется из `isuGroup203` / `isuGroup204`. Подробнее — в [docs/CODE.md](docs/CODE.md#расписание-ису).

## Что нового в Спринте 3

- Строгий Material 3, индиго-палитра, тёмная тема на нейтральном чёрном, AMOLED; убраны служебные подписи и «//»-подсказки.
- Нижняя панель на выбор: статичная или плавающий овал (иконки, подпись у выбранной); анимация смены вкладок — бета, по умолчанию выключена.
- Ускоренное закрытие экрана жестом «назад».
- Доска: вкладки колонок (точка цвета, полное название, счётчик), свайп по доске листает колонки,
  «Выполнено N из M», полоса приоритета на карточке. Действия с карточкой — по долгому нажатию.
- Редактор колонок: только название и цвет четырёх стандартных колонок (свои этапы убраны — в вебе их нет).
- Парсер расписания ИСУ УУНиТ для групп 203/204 с кэшем на устройстве; группа выбирается в меню «Моё расписание»;
  компактный фильтр категорий; чужие личные события показываются по настройке приватности владельца.
- Проекты: двойное нажатие делает проект активным на доске.
- История: три одинаковые карточки-показателя, записи отдельными карточками, без дублирования дат.
- Профиль: «Настройки аккаунта» (группа, фото, приватность) и «Настройки приложения» (тема, панель, анимация, обои,
  push, папка для файлов), экран уведомлений, участники с поиском; капитан создаёт аккаунты, блокирует, сбрасывает пароль.
- Файлы задач и проектов открываются внутри приложения (изображения, PDF, текст) и сохраняются в выбранную папку
  с подпапкой по имени проекта.
- Результат задачи загружает только исполнитель (BUG-08 / QA-02) — капитан тоже сначала назначает задачу на себя.
