# Kanban Mobile

Нативное Android-приложение команды на Kotlin и Jetpack Compose. Модуль создан в рамках Sprint 0 и повторяет визуальный язык веб-клиента.

## Быстрый запуск

1. Откройте каталог `mobile` в Android Studio.
2. Выберите JDK 17 (встроенный JBR Android Studio подходит).
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на эмуляторе с Android 8.0 (API 26) или новее.
5. Войдите под тимлидом `alexey / lead123` или участником `maria / member123`.

Проверка из терминала Windows:

```powershell
cd mobile
.\gradlew.bat test assembleDebug
```

APK после сборки: `mobile/app/build/outputs/apk/debug/app-debug.apk`.

## Реализовано в Sprint 0

- вход по логину и паролю с разделением прав;
- Kanban-доска с четырьмя статусами;
- создание задачи для тимлида, карточка задачи, смена статуса, файлы и комментарии;
- история выполненных задач с поиском и фильтрацией;
- список участников и публичный профиль участника;
- управление командой, блокировка пользователей и создание аккаунтов для тимлида;
- выбор временного пароля при создании аккаунта;
- права на смену статуса: исполнитель работает со своей задачей, тимлид принимает результат;
- выбор дедлайна задачи через системный календарь;
- фильтрация истории за 7/30 дней или за всё время;
- список команд, карточка команды, выбор рабочей команды, вступление и выход;
- личный профиль со статистикой;
- дополнительные разделы расписания групп 203/204 и событий;
- единая с веб-клиентом цветовая система и геометрия компонентов.

Данные пока не сохраняются после перезапуска. Точки замены mock-слоя на backend описаны в корневом файле `MOBILE_DEVELOPMENT.md`.
