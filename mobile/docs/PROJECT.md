# Канбан-доска — Android-приложение

## О проекте

«Канбан-доска» — система ведения работы студенческой команды «Код в сапоге» (УУНиТ, ИИМРТ, группы ТОП-203Б и ТОП-204Б).
Она объединяет в одном месте то, что обычно разнесено по чатам, документам и ИСУ:

- канбан-доски проектов (лабораторные, хакатоны, курсовые, свои проекты);
- учебное расписание групп 203 и 204 и командные события;
- историю выполненных задач и прозрачный прогресс для капитана.

Система: backend на Go (REST, PostgreSQL), веб-клиент на React + TypeScript и это Android-приложение
(Kotlin, Jetpack Compose, Material 3). Репозиторий — `NikitaKovalenko111/kanban-board`, мобильная часть — папка `mobile/`.

Сейчас приложение работает в **демо-режиме**: вместо сервера — локальный демо-сервер, который проверяет права так же,
как должен проверять backend, и **сохраняет данные на устройстве** между запусками. Экраны работают через интерфейсы
репозиториев, поэтому при подключении API они не меняются.

При первом запуске есть только два аккаунта — тимлид и участник. Проекты, задачи, события и остальных участников
создают сами пользователи.

## Роли

| Роль | Кто | Что может сверх участника |
|---|---|---|
| Капитан (тимлид) | `nikita` и те, кого назначат капитаном | создаёт и редактирует проекты и задачи, удаляет задачи, назначает исполнителей и может переназначить задачу на себя, принимает и возвращает задачи, меняет название и цвет колонок, создаёт аккаунты, блокирует и восстанавливает доступ, сбрасывает пароли, создаёт групповые события для любой группы |
| Участник | `samir` и созданные капитаном | берёт свободные задачи, ведёт свои задачи до проверки, комментирует, создаёт события (групповые — только для своей группы), добавляет источники в свои проекты |

Аккаунты создаёт только капитан, самостоятельной регистрации нет.

## Разделы приложения

Нижняя панель: **Доска · Расписание · Проекты · История · Профиль**. Стиль панели (статичная / плавающий овал)
и анимация смены вкладок настраиваются в профиле. Анимация вкладок — бета-функция, по умолчанию выключена;
при включении в настройках показывается красное предупреждение.

### Доска
- Активный проект выбирается в заголовке (или двойным нажатием на проект во вкладке «Проекты»).
- Колонки — вкладки с точкой цвета, названием и числом задач; свайп влево-вправо переключает колонки.
- Над вкладками — «Выполнено N из M» с полосой прогресса. В «Выполнено» видны 5 последних задач, остальные — в «Истории».
- Карточка: полоса приоритета, исполнитель или «Свободная», счётчики комментариев и файлов, срок.
- Нажатие открывает задачу, долгое нажатие — меню «Взять / Переместить».
- Капитан: «Задача» (создание) и «Колонки» (редактор: только название и цвет). На доске всегда четыре колонки —
  Ожидает / В работе / На проверке / Выполнено; свои этапы, порядок и удаление колонок убраны (в вебе их нет).

### Задача
- Описание, исполнитель, срок, автор, время выполнения.
- Кнопки по правам: «Взять в работу», «Сдать на проверку», «Принять задачу», «Вернуть на доработку» (только с замечанием), «Переместить…».
- Файлы: «Исходники» (добавляет капитан) и «Результат» (добавляет **только исполнитель**). Файл открывается во встроенном просмотрщике.
  Удаление файла заблокировано до решения команды (в вебе его нет).
- Капитан может «Назначить на себя» чужую задачу (BUG-08: явное переназначение), после этого сдаёт её как исполнитель.
- Журнал всех действий и комментарии.

### Расписание
- Лента дня со свайпом по дням и полоса недели.
- Пары с ИСУ УУНиТ для групп 203 и 204, кэш на устройстве; без сети — плашка «показан кэш».
- Меню расписания:
  - «Моё расписание» — моё полное расписание: пары своей группы, события, дедлайны; работает фильтр категорий;
  - «Группа 203», «Группа 204», «Обе группы» — только пары выбранных групп, фильтр категорий заблокирован;
  - участники — расписание человека с учётом его приватности.
  Высота меню ограничена, участники прокручиваются внутри.
- Фильтр категорий (меню с галочками): пары, команда, группа, личное, дедлайны.
- События: видимость команда / группа / лично, необязательное окончание, место, типы событий с цветом.
- Напоминания личные: на любую пару и любое событие, из готовых интервалов или свои.
- Чужие личные события показываются по настройке приватности владельца (см. ниже).

### Проекты
- «Мои» и «Остальные». Двойное нажатие — сделать проект активным на доске.
- Карточка проекта: описание, состав с ролями, источники — ссылки и файлы.
- Капитан создаёт проекты и редактирует состав и роли (нельзя исключить человека с незакрытыми задачами).
  Удаление проекта заблокировано до решения команды.

### История
- Выполненные задачи всех проектов по дням; период «Неделя / Месяц / Всё время», фильтры по проекту и исполнителю, поиск.
- Три показателя: выполнено, возвратов, средний цикл (от взятия в работу до принятия).

### Профиль
- **Настройки аккаунта**: учебная группа, фото профиля (смена и удаление), приватность расписания, смена пароля.
- **Настройки приложения**: тема (системная / светлая / тёмная / AMOLED), нижняя панель, анимация вкладок,
  свои обои (хранятся только на устройстве), push о задачах и событиях, папка для сохранения файлов, список уведомлений.
- **Уведомления**: комментарии, возвраты, смена статуса, ближайшие события. При открытии экрана всё отмечается прочитанным.
- **Участники**: одна плашка «Участники» с числом людей → полный список с поиском. Нажатие открывает окно с данными участника.
  Капитан в этом окне: блокировка/восстановление, сброс пароля (новый временный пароль показывается один раз),
  «Сделать капитаном» / «Снять роль капитана» и удаление аккаунта (эти две функции заблокированы до решения команды).
  Кнопка «Добавить» создаёт новый аккаунт.
- Удалить нельзя себя и человека с незакрытыми задачами (их сначала переназначают). При удалении человек убирается
  из проектов, его личные события удаляются, командные события и его типы событий переходят капитану,
  выполненные задачи, комментарии и журнал остаются.

## Приватность расписания

Каждый выбирает в настройках аккаунта, что другие видят о его **личных** событиях:

| Настройка | Что видят другие |
|---|---|
| Ничего | событие не показывается |
| Только «Занят» (по умолчанию) | время и надпись «Занят» |
| Название | время и название |
| Название и описание | время, название и описание (место скрыто) |

Командные и групповые события видны всем, кому они адресованы.

## Матрица прав по задачам

| Действие | Капитан | Исполнитель | Другой участник |
|---|---|---|---|
| Создать, изменить, удалить задачу | да | нет | нет |
| Взять свободную задачу | да | — | да |
| Взять чужую задачу | через назначение | — | нет (QA-01) |
| Ожидает → В работе | да | да | нет |
| В работе → На проверке | только если исполнитель | да | нет |
| На проверке → Выполнено | да | нет | нет |
| Вернуть на доработку | да, с замечанием | нет | нет |
| Добавить исходники | да | нет | нет |
| Добавить результат | только если исполнитель | да | нет (QA-02, BUG-08) |
| Назначить задачу на себя | да | — | нет |
| Удалить файл задачи | заблокировано | заблокировано | заблокировано |
| Название и цвет колонок | да | нет | нет |

Права зависят от **позиции** колонки, а не от названия: первая — «ожидание», последняя — «готово», предпоследняя — «проверка»,
все между ними — рабочие этапы. Колонки можно переименовывать, их состав и порядок фиксированы.

## Файлы

- Прикреплённый файл копируется в хранилище приложения (до 10 МБ) и открывается внутри: изображения, PDF (до 50 страниц), текст.
  Остальные типы — кнопкой «Открыть в другом приложении».
- «Сохранить» кладёт копию в папку, выбранную пользователем, в подпапку с именем проекта (`Папка/Проект/файл`).
  Папку можно задать заранее в настройках приложения.

## Ограничения текущей версии

- Демо-режим: данные хранятся только на этом устройстве, другие участники их не видят — общими они станут после
  подключения REST API. Файлы и фото тоже хранятся только на устройстве.
- Парсер ИСУ написан без доступа к реальной разметке сайта (сайт закрыт для автоматических запросов из среды разработки).
  Он опирается на содержимое строк таблицы, а не на CSS-классы; нужно проверить на сохранённой странице и закрепить тестом.
  Пока страница не распознана — показывается кэш, а без кэша пар нет и висит предупреждение (выдуманных пар нет).
- Push о задачах — локальные уведомления по изменениям в демо-состоянии; с backend их заменит FCM.
- Сброс пароля и блокировка работают в демо-сервере; на backend понадобятся соответствующие эндпоинты.
